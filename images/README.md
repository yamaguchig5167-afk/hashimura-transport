## 表示サイズ違いのファイル（-sm / -md）

スマートフォンでの通信量を減らすため、同じ写真を3サイズ用意して
HTML側の `srcset` で出し分けている。

| 接尾辞 | 幅 | 主に使われる端末 |
|---|---|---|
| `-sm.jpg` | 480px | 画面密度が標準のスマホ |
| `-md.jpg` | 720px | 一般的なスマホ（画面密度2倍）|
| （なし） | 900px | タブレット・パソコン |

ヒーロー背景はCSS指定のため `srcset` が使えず、600px以下では
`hero-fleet-sm.jpg`（幅800px）をCSSのメディアクエリで指定している。

**写真を差し替えたら、必ず3サイズとも作り直すこと。**

```bash
magick 元画像.jpg -resize 900x -strip -interlace Plane -sampling-factor 4:2:0 -quality 83 名前.jpg
magick 名前.jpg -resize 720x -strip -interlace Plane -sampling-factor 4:2:0 -quality 79 名前-md.jpg
magick 名前.jpg -resize 480x -strip -interlace Plane -sampling-factor 4:2:0 -quality 80 名前-sm.jpg
```

`srcset` の `sizes` を変えるときは、実機幅375pxで
「表示幅 × 画面密度」がどのサイズに当たるかを確認すること。
`sizes` が実際の表示幅より大きいと、常に900px版が選ばれて効果がなくなる。

## 写真の枠と切り抜き（2026-10-03 改訂）

**掲載写真はすべて 16:9（約1.778）に統一し、枠も16:9にしている。**
縦横比が一致しているため、表示時の切り落としもレターボックスも出ない。

写真を差し替えるときは、**元画像の時点で被写体が中央に来る16:9に切ってから**置くこと。
元の写真はどれも下半分が路面で、そのまま入れると車両が上に寄って見える。

切り出し位置は実画像に座標グリッドを重ねて被写体の位置を実測して決めた。
作業スクリプトの考え方は下の検査コードと合わせて残している。

### img の width/height と srcset は実ファイルから書き直す

切り直すと実寸が変わる。属性とずれるとブラウザが誤った版を選び、
読み込み前の場所取りも狂う。切り直したら必ず全HTMLの属性を実寸に合わせる。

## 写真の枠と切り抜き（2026-09-09 修正）

**枠の高さを固定して `object-fit: cover` にしない。** 写真の縦横比が枠と違う分だけ
車両が強制的に切り落とされ、実測で最大49%（`fleet-unic.jpg`）が欠けていた。

現在の方式は2通り。

| 用途 | 指定 | 理由 |
|---|---|---|
| 単独・2枚並びの写真<br>（保有車両・サービス詳細・安全講習・ヤード作業） | 枠を固定せず元の縦横比のまま | 切り落としも余白も出ない。車両が一番大きく見える |
| カルーセル・車両カード・職種カード | `aspect-ratio: 16/9` ＋ `object-fit: contain` | 高さが揃わないと並びが崩れるため。containなので車両は必ず枠内に収まる |

`contain` を使う場合は **CSSに `height: auto` を必ず書く**。
`<img>` の `height` 属性が presentational hint として効いてしまい、
`aspect-ratio` が無視される（実際に車両カードの高さが271pxではなく486pxになっていた）。

写真を追加したら、ブラウザで以下を実行して**切れが0件**であることを確認する。

```js
[...document.querySelectorAll('img')].filter(i=>i.naturalWidth).map(i=>{
  const r=i.getBoundingClientRect(), f=getComputedStyle(i).objectFit;
  const box=r.width/r.height, src=i.naturalWidth/i.naturalHeight;
  const d=Math.max(src>box?1-box/src:0, src<box?1-src/box:0);
  return {src:i.currentSrc.split('/').pop(), fit:f, 差:Math.round(d*100)+'%'};
}).filter(x=>x.fit==='cover' && x.差!=='0%')
```

## 写真を扱うときの注意（重要）

### 1. 旧グループ会社名が車体に入っている

車両の多くに **「物流ハシムラ」** の社名が入っています。
サイト上は「先導車事業部／出荷ヤード作業事業部」表記に統一しているため、
**車体の社名が明瞭に読める写真は使用しない**か、トリミングで外すこと。
現在採用している写真は、いずれも社名が判読できない構図を選んでいます。

### 2. 従業員が写る写真

**安全講習の2枚（`safety-meeting.jpg` / `safety-training.jpg`）は、いずれも外部で行われた講習**です
（2026-09-09 橋村運送様に確認）。社内研修と書かないこと。

`safety-meeting.jpg` は**橋村運送様のご指示により掲載**しています。
受講者はいずれもマスク着用で後ろ姿または横顔であり、掲載サイズでは
個人を識別できない構図を選んでいます。
**正面から顔が写る写真を追加する場合は、事前に本人の同意が必要です。**

`safety-training.jpg`（外部会場の安全講習）は受講者が全員後ろ姿で、
講師も掲載サイズでは顔を識別できません。
`yard-loading.jpg` / `yard-crane.jpg` の作業員はヘルメット着用の後ろ姿・遠景です。

`team-photo.jpg`（社員の集合写真・約26名）は全員が正面から写るため、
**2026-09-09に橋村運送様から掲載の承諾をいただいたうえで公開**しています。
車体の社名は人物に隠れており、拡大確認しても「物流ハシムラ」は判読できません。

**この写真を差し替える・別の顔が写る写真を追加する場合は、
その都度あらためて承諾を得ること。**一度の承諾は他の写真には及びません。

### 3. 取引先の社名・ロゴ

安全教育の写真には壁面に「九州髙圧コンクリート工業株式会社」の社名が
大きく写り込んでいたため、**上端をトリミングして除外**しています。
このため `safety-meeting.jpg` は元画像の上部を切ってはいけません。
新しい写真を追加する際も、他社の社名・ロゴが写っていないか確認すること。

`safety-training.jpg` は壁面の掲示物を拡大確認済みで、
交通安全の一般啓発ポスターのみ（他社の社名・ロゴなし）。

## 画像を差し替える手順

同じファイル名で上書きするだけで反映されます。サイズは上表に合わせてください。

書き出しの推奨設定（ImageMagickの例）：

```bash
magick 元画像.jpg -resize 1477x -strip -interlace Plane -sampling-factor 4:2:0 -quality 82 hero-fleet.jpg
```

- `-strip` … 撮影位置などのEXIF情報を削除（公開前に必須）
- `-quality 82` … 画質と容量のバランス。1枚300KB以内を目安に

OGP画像（`ogp.jpg`）を差し替えた後は、
[Facebook シェアデバッガー](https://developers.facebook.com/tools/debug/) でキャッシュを更新してください。

## カルーセルの写真を入れ替える

1. 新しい写真を `gallery-0X.jpg`（幅900px・上表の書き出し設定）として配置する
2. `index.html` の「現場のいま」セクションで、その番号の `<img>` の `alt` と
   `<figcaption>` を写真の内容に合わせて書き換える
3. 枚数を増やす場合は `<li class="gallery__item">` を複製する。
   インジケータ（ドット）はJSが枚数に合わせて自動生成するので調整不要

**採用しなかった写真**：夕暮れの出発（IMG_1253）と夜間運行（IMG_1257）は
構図が良いものの、車体の「物流ハシムラ」が明瞭に読めるため見送っている。
表記方針が変わった場合は追加候補になる。
