## 写真を扱うときの注意（重要）

### 1. 旧グループ会社名が車体に入っている

車両の多くに **「物流ハシムラ」** の社名が入っています。
サイト上は「先導車事業部／出荷ヤード作業事業部」表記に統一しているため、
**車体の社名が明瞭に読める写真は使用しない**か、トリミングで外すこと。
現在採用している写真は、いずれも社名が判読できない構図を選んでいます。

### 2. 従業員が写る写真

`safety-bg.jpg` は安全教育の様子ですが、**個人が特定できないよう強くぼかし**、
不透明度14%の背景としてのみ使用しています。
顔が判別できる状態で使用する場合は、事前に本人の同意が必要です。

### 3. 取引先の社名・ロゴ

元写真には取引先の社名が写り込んでいたため、トリミングで除外しています。
新しい写真を追加する際も、他社の社名・ロゴが写っていないか確認すること。

## 画像を差し替える手順

同じファイル名で上書きするだけで反映されます。サイズは上表に合わせてください。

書き出しの推奨設定（ImageMagickの例）：

```bash
magick 元画像.jpg -resize 1477x -strip -interlace Plane -sampling-factor 4:2:0 -quality 82 hero-fleet.jpg
```

- `-strip` … 撮影位置などのEXIF情報を削除（公開前に必須）
- `-quality 82` … 画質と容量のバランス。1枚300KB以内を目安に

OGP画像（`ogp.jpg`）を差し替えた後は、
[Facebook シェアデバッガー](https://developers.facebook.com/tools/debug/) でキャッシュを更新してください。
