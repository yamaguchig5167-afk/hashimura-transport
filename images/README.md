## 写真を扱うときの注意（重要）

### 1. 旧グループ会社名が車体に入っている

車両の多くに **「物流ハシムラ」** の社名が入っています。
サイト上は「先導車事業部／出荷ヤード作業事業部」表記に統一しているため、
**車体の社名が明瞭に読める写真は使用しない**か、トリミングで外すこと。
現在採用している写真は、いずれも社名が判読できない構図を選んでいます。

### 2. 従業員が写る写真

`safety-meeting.jpg`（安全教育）は**橋村運送様のご指示により掲載**しています。
受講者はいずれもマスク着用で後ろ姿または横顔であり、掲載サイズでは
個人を識別できない構図を選んでいます。
**正面から顔が写る写真を追加する場合は、事前に本人の同意が必要です。**

### 3. 取引先の社名・ロゴ

安全教育の写真には壁面に「九州髙圧コンクリート工業株式会社」の社名が
大きく写り込んでいたため、**上端をトリミングして除外**しています。
このため `safety-meeting.jpg` は元画像の上部を切ってはいけません。
新しい写真を追加する際も、他社の社名・ロゴが写っていないか確認すること。

## 画像を差し替える手順

同じファイル名で上書きするだけで反映されます。サイズは上表に合わせてください。

書き出しの推奨設定（ImageMagickの例）：

```bash
magick 元画像.jpg -resize 1477x -strip -interlace Plane -sampling-factor 4:2:0 -quality 82 hero-fleet.jpg
```

- `-strip` … 撮影位置などのEXIF情報を削除（公開前に必須）
- `-quality 82` … 画質と容量のバランス。1枚300KB以内を目安に

OGP画像（`ogp.jpg`）を差し替えた後は、
[Facebook シェアデバッガー](https://developers.facebook.com/tools/debug/) でキャッシュを更新してください。

## カルーセルの写真を入れ替える

1. 新しい写真を `gallery-0X.jpg`（幅900px・上表の書き出し設定）として配置する
2. `index.html` の「現場のいま」セクションで、その番号の `<img>` の `alt` と
   `<figcaption>` を写真の内容に合わせて書き換える
3. 枚数を増やす場合は `<li class="gallery__item">` を複製する。
   インジケータ（ドット）はJSが枚数に合わせて自動生成するので調整不要

**採用しなかった写真**：夕暮れの出発（IMG_1253）と夜間運行（IMG_1257）は
構図が良いものの、車体の「物流ハシムラ」が明瞭に読めるため見送っている。
表記方針が変わった場合は追加候補になる。
